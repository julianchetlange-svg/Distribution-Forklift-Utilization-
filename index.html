DC Detail — Removal Opportunities

Methodology: Removal candidates are identified using the 80% of store fleet average HPD threshold (2.643). This more aggressive threshold reflects that DCs run multiple shifts where underutilization is more material than at stores. At each DC, the oldest unit of the targeted type class is pulled. Forklifts of larger capacity can absorb workload from smaller classes (e.g. an 11K can handle 10K work, a 13K can handle 11K work), so the analysis does not require keeping a unit of every capacity class — it considers the full fleet at each DC as the workload-absorbing pool. Workload is conserved across the remaining fleet.
